# Sample-server code in the X module (`crm.so`)

`usr/lib/X11/dyDDX/crm.so` carries the machine-independent and memory-drawing layers of the public X Window System sample server next to its CRIME code. This chapter gives each such routine of the 6.5.30 module its own entry: what it does, the public source file that holds the same routine, and whether it reaches CRIME hardware. None of the routines below touches the CRIME register windows: they draw into memory, and the CRIME routines of [xmodule.md](xmodule.md) call them as the generic path.

Public source: the X.Org server tree at tag `XORG-6_8_2` (`https://gitlab.freedesktop.org/xorg/xserver`, directories `mi`, `cfb` and `mfb`), which descends from the X11R6.6 sample server the IRIX server was built from. Paths in the entries are relative to that tree. The 16-bit and 32-bit `cfb` routines are the `cfb` source compiled for those pixel sizes, and the names with a `..` suffix are file-local routines whose suffix the module's symbol table adds.

Labels follow [AGENTS.md](../AGENTS.md): an entry is **Established** only where the whole routine was read against the public body; the rest are **Inferred**, matched to the public routine by its calls and shape rather than read end to end. Where an entry says it differs from the public body, the difference was read in the disassembly. Routes tried for the SGI-only code (the symbol-database reader, the line-table helpers and the `nfb` layer, which has no public counterpart): the public X.Org tree holds none either.

The 165 `nfb` routines have their own chapter, [nfb-layer.md](nfb-layer.md).
