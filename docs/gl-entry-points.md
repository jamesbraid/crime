# libGLcore: the OpenGL entry points

The public entry points of the CRIME build of `libGLcore.so` (`usr/gfx/arch/IP32CRM/` and `IP32CRM32/`), grouped by what the OpenGL 1.2 specification and the vendor extension specifications define them to do. The role of each is the specified one; what it does to CRIME (which registers it writes, which software fallback it takes) is in [opengl.md](opengl.md). Labels: **established** that the symbol is exported (read from the dynamic symbol table); the role is the published API's.
